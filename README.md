# Optical Lift

A deliberately small, static parent-company site for Optical Lift.

## Editing the homepage

Most routine copy changes belong in `content/home.ts`.

The layout is in `app/page.tsx` and the Hive-inspired editorial design system is in `app/globals.css`.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The site has no CMS, database, authentication, or server-side business logic.

## Public destinations

- Atlas: https://atlas.opticallift.com
- Stationery: https://stationery.opticallift.com

Infrastructure and deployment configuration are intentionally outside the scope of this repository setup.
